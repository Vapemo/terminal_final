
# 🖥️ Terminal de Trabajo — Proyecto Final

¡Bienvenido a **Terminal de Trabajo**!  
Un sistema interactivo que simula una terminal para gestionar archivos, consultar información del sistema, reproducir música, jugar y mucho más.

---

## 🎯 Características principales

- 🔐 **Sistema de Acceso**:  
  Inicio de sesión con usuario y contraseña reales del sistema operativo anfitrión. Solo usuarios válidos pueden ingresar.
  Para probarlo en tu terminal se tiene que crear un usuario con sudo adduser usuario1 y la contrasela tiene que ser protecsa

- 🧰 **Línea de Comandos**:  
  Terminal amigable con comandos personalizados para:
  - Navegar, buscar y trabajar con archivos.
  - Consultar información del sistema.
  - Reproducir música MP3.
  - Jugar.
  - Salir de forma controlada.

- 🛠️ **Consulta de Información**:
  - Memoria RAM disponible.
  - Arquitectura del sistema.
  - Versión del sistema operativo.

- 🎮 **Juegos Integrados**:
  - **Ahorcado**: Adivina palabras.

- 🔚 **Sistema de Salida Controlada**:
  - Comando `salir` que cierra la terminal de forma segura.
  - Protección contra `Ctrl+Z` para evitar suspensiones accidentales.

---

## 🧾 Comandos Disponibles

| Comando    | Descripción                                           |
|:----------:|:------------------------------------------------------|
| `ahorcado` | Inicia el juego del ahorcado.                          |
| `ayuda`    | Muestra todos los comandos disponibles y su uso.       |
| `buscar`   | Permite buscar archivos dentro del sistema.            |
| `creditos` | Muestra los desarrolladores del proyecto.              |
| `fecha`    | Muestra la fecha y hora actual del sistema.            |
| `infosis`  | Muestra información de memoria, arquitectura y versión.|
| `login`    | Sistema de acceso por usuario y contraseña.            |
| `main`     | Script principal que lanza la terminal.                |
| `mp3`      | Abre el reproductor de música para archivos MP3.        |
| `salir`    | Cierra la terminal de forma segura.                    |
